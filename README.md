# My resume

This is a game-like resume built with PixiJs.

![interactive resume](https://media4.giphy.com/media/v1.Y2lkPTc5MGI3NjExZXZ0bTY1Z3JkZzNubW1wbTUzcnU0Zmw3YWw3d2RnM2E4Njdya254cyZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/SRZgIFqL3BxUshGZeN/giphy.gif)

A plain version is served beside it, for anyone (or any applicant-tracking system)
that can't play a game: [resume.pdf](https://thypirate.github.io/my-resume/resume.pdf) and
[resume.html](https://thypirate.github.io/my-resume/resume.html). Both are generated from `src/data/`,
so after editing anything there run `npm run resume` (needs Node 23.6+ and Chrome) and commit the result.

## Quick start

```bash
git clone https://github.com/thypirate/my-resume.git
cd my-resume
npm install
npm run dev
```

Then open `http://localhost:5173` in a browser.
